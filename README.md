### 🧑‍💻 About me

I'm a backend-focused **Senior Full-Stack Engineer & DevOps** who designs, builds, and operates scalable, high-traffic web platforms where correctness and uptime matter.

My day to day is system design, API architecture, real-time systems, cloud infrastructure, observability, and automated testing. I like owning a product end to end: shaping the requirements and architecture, building the backend and the frontend, shipping it, and keeping it healthy in production. I've led teams and client-facing projects as a Technical Lead, and I've mentored **200+ students** worldwide.

I try not to get too attached to any single tool. I'd rather pick what fits the problem and keep learning along the way.

### 🏗️ What I'm building now

- 🔌 A **versioned REST API** consumed by web and mobile clients, with its versioning strategy and technical docs
- 🗄️ **PostgreSQL** data layer with **Redis** for caching, sessions, and background job queues, plus real-time features across the app
- 🐳 **Dockerized** frontend and backend with parity from local dev to production, deployment pipelines, and server administration
- 📡 Full **Grafana observability stack**: Prometheus metrics, Mimir long-term storage, Loki logs, Tempo distributed tracing, and Sentry for exceptions and release monitoring
- 🧪 Unit and end-to-end test coverage as a release gate, plus **k6** load and stress testing to find throughput ceilings before every deployment
